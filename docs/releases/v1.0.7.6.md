# VNV Korean Patcher v1.0.7.6 — 키 안내 한글 깨짐 수정

점프 튜토리얼 등에서 키 이름 주변의 `누르기`·`또는`이 깨지는 문제를 수정합니다. 게임이 키 안내를 조립할 때 사용하는 `sPCControlsTextPrefix`와 `sOr`를 CP949로 제공합니다. VNV 실제 게임에서 테스트 수정 후 정상 표시를 확인했습니다.

사용자가 재설정한 키와 컨트롤러 버튼을 표시하는 기존 치환은 유지합니다. `Space`를 고정 입력하지 않습니다. DLL·폰트·해킹 화면 수정과 다른 번역은 그대로입니다. 패키지의 두 GMST와 해당 체크섬만 변경됐는지 검증합니다.

새 패쳐로 Output을 생성한 뒤 `VNV Korean UI Strings/VNVKR UI Strings.esp`를 기존 모드에 적용하세요. 현재 테스트 수정을 적용한 VNV 설치는 이미 같은 수정이 적용돼 있습니다.
