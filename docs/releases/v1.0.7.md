Viva New Vegas 한국어 패처 v1.0.7입니다. 기존 SST/XEditLib 번역 방식에 MO2 자동 설치와 프로필 자동 활성화를 추가했습니다.

- **tNVSE GMST·단축키 인코딩 수정:** 문자열 치환 후 삽입되는 UTF-8 텍스트를 기존 변환기로 처리하는 수정 DLL을 기존 `VNV Korean Fonts - tNVSE` 폴더에 포함합니다. 원본 **tNVSE 71**과 선행 모드는 가이드대로 먼저 설치해야 합니다.
- **MO2 설치 경로 수정:** 기존 모드의 번역본은 실제 Mods 경로에 덮어씁니다. 게임 Data에만 있는 플러그인은 `VNV Korean Translations` 모드로 보내고, Courier's Stash 4개 ESM은 Fixed ESMs에 설치합니다. Overwrite 플러그인은 백업 후 번역 모드로 옮깁니다. 게임 Data 원본은 유지합니다.
- **선택한 프로필 자동 활성화:** 필요한 한국어 폰트·라디오·UI 모드와 플러그인을 `modlist.txt`, `plugins.txt`, `loadorder.txt`에 반영합니다. 기존 비활성 선택 모드는 유지합니다.
- **백업·복구:** 교체 전 파일과 프로필을 `Output.backup`에 보관하고 설치 실패 시 되돌립니다. MO2를 종료하고 `VNVKoreanPatcher-v1.0.7.exe --restore "백업 폴더 전체 경로"`로 복구할 수 있습니다.
- 기존 EXE에 포함된 라디오/UI 및 터미널 텍스처의 누락된 설치 선언을 복구했습니다.

MO2에서 적용할 프로필을 선택한 뒤 MO2를 종료하세요. 아래 EXE를 실행해 `ModOrganizer.ini`가 있는 VNV 인스턴스 폴더를 선택하고 **한국어 패치 설치**를 누르면 됩니다. 별도 Python 설치나 Output 수동 복사는 필요하지 않습니다.

검증: Linux/Windows 회귀 테스트 49개, 실제 tNVSE 함수의 C++ 문자열 변환 테스트, 단일 EXE 패키지 검증을 통과했습니다. **실제 게임의 GMST·단축키 표시와 라이브 MO2 적용 확인은 아직 진행하지 않았습니다.**

수정 tNVSE의 GPL-3.0 라이선스와 해당 소스는 EXE에 포함되며, 소스 ZIP도 별도 첨부했습니다. `SHA256SUMS.txt`에서 배포 파일의 해시를 확인할 수 있습니다.
