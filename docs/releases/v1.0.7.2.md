Viva New Vegas Extended 프로필을 대상으로 Output을 생성하는 수정 릴리즈입니다.

- GUI 패쳐는 현재 선택된 프로필과 관계없이 `Viva New Vegas Extended`를 사용합니다. 해당 프로필이 없으면 생성이 중단됩니다.
- `Output/profiles/Viva New Vegas Extended`에 활성화 설정을 반영한 세 텍스트 파일을 생성합니다.
- 기본 복사 대상은 `C:\Modlist\VNV\profiles\Viva New Vegas Extended`입니다. 외부 Profiles 경로는 `INSTALL.txt`를 따르세요.
- MO2와 게임 파일은 직접 수정하지 않으며, 사용자가 Output 파일을 복사해 덮어씁니다.
- 수정 tNVSE DLL과 기존 번역을 유지합니다. 실제 게임의 GMST·단축키 표시는 최종 확인이 남아 있습니다.
