v1.0.7의 직접 설치 동작을 바로잡은 수정 릴리즈입니다.

- **MO2와 게임 파일에 직접 쓰는 자동 설치·이동·삭제 기능을 제거했습니다.**
- 번역 파일과 `modlist.txt`, `plugins.txt`, `loadorder.txt`를 Output에만 생성합니다.
- 사용자가 Output의 파일을 `INSTALL.txt`에 안내된 실제 Mods/프로필 경로로 복사해 덮어씁니다.
- 필요한 한국어 모드·플러그인 활성화는 복사할 프로필 텍스트에 미리 반영합니다.
- tNVSE 수정 DLL과 기존 SST/MCM/라디오/UI 번역은 유지합니다.

MO2를 종료한 뒤 **Output 생성**을 누르고, 기존 파일과 프로필을 백업한 다음 Output의 파일을 수동 복사하세요. 모드 파일을 먼저 병합하고 프로필 텍스트를 마지막에 덮어쓰세요. 생성 후 설정을 바꿨다면 새 Output을 만드세요.

1.0.7로 이미 설치한 경우 기존 백업은 보관하세요. 이 버전은 기존 설치를 자동 복구하거나 변경하지 않습니다. 실제 게임의 GMST·단축키 표시 확인은 아직 진행하지 않았습니다.
