# v1.0.7.5 — 터미널 해킹 폰트 간격

- 해킹 UI의 17 단위 셀에 맞춰 폰트 슬롯 5의 영문·기호를 `fixedWidth=17`, `tracking=0`으로 설정합니다. 기존 NeoDunggeunmo Pro는 영문·기호의 폭이 서로 달라 고정 간격 UI와 맞지 않았습니다.
- 영문·기호 크기를 22에서 28로 키우고 `scaleX=0.8`을 적용합니다. 가장 넓은 `@`를 포함한 출력 가능한 ASCII 94자의 윤곽과 외곽선이 17×28 영역에 들어가는지 검사합니다.
- 기존 DLL의 고정폭 기능을 사용합니다. DLL·INI·한글 폰트 설정·다른 폰트 슬롯·번역·백엔드 파일은 이전 배포와 같습니다. 슬롯 5를 공유하는 일반 터미널의 영문에도 적용됩니다.

폰트·패키징 테스트 11개, ASCII 94자 윤곽 검사 및 EXE 패키지 검사를 통과했습니다. 기존 배포와 비교해 폰트 XML과 해당 체크섬만 변경되었습니다. 오프라인 검사만으로 게임 화면 정상 표시를 확정할 수 없습니다. 실제 게임에서 해킹 문자열과 커서/선택 영역, 괄호 선택, 추측 기록 및 한글 일반 터미널을 확인해야 합니다.

새 패쳐로 Output을 다시 생성해 적용하세요. 빠른 적용은 게임과 MO2를 종료하고 기존 `VNV Korean Fonts - tNVSE/NVSE/plugins/tnvse_fonts.xml`을 백업한 뒤, 핫픽스 ZIP의 같은 경로 파일을 덮어씁니다. 원본 tNVSE 71 및 기존 한글 폰트 모드가 필요합니다. 되돌릴 때는 백업한 XML을 복원합니다.
